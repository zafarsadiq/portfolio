# Zafar Sadiq – Portfolio

One-page portfolio built with Next.js 14 (App Router), TypeScript and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
npm start
```

## Edit content

- All text, projects, tools and contact details live in `lib/data.ts`.
- Project screenshots are in `public/projects/`, your photo is `public/photo.jpg`.
- Colors and fonts are set in `tailwind.config.ts`.
- Sections are in `components/`, in page order: Nav, Hero, About, Tools, Experience, Projects, Education, Contact.

## Deploy

Push to GitHub and import the repo in Vercel, or run `npm run build && npm start` on any Node 18+ host.
